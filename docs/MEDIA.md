## How to record

- **Terminal GIFs:** [VHS](https://github.com/charmbracelet/vhs) records
  a scripted terminal session, so the GIF can be re-made after every
  release with one command. Install it (`winget install charmbracelet.vhs`,
  `brew install vhs` or `go install github.com/charmbracelet/vhs@latest`),
  then run `vhs docs/media/<name>.tape` from the repository root.
- **Editor and browser GIFs:** [ScreenToGif](https://www.screentogif.com)
  (Windows) or [Kap](https://getkap.co) (macOS). Record a window of about
  1000 x 600 pixels at 12-15 frames per second.
- **Size:** keep each GIF under 5 MB and 10-25 seconds (GitHub shows GIFs
  up to 10 MB inline); crop to the window, use a large font (16-18 pt),
  and pause 1-2 seconds on the result. For longer demos, an MP4 under
  10 MB can be dragged into a GitHub issue or README edit instead.
- **Placing:** save the file under `docs/media/` with the name below. In
  README.md, the matching `<!-- GIF placeholder: ... -->` comment marks
  the spot; replace the comment with

  ```markdown
  ![Short description of what happens](https://raw.githubusercontent.com/SAMtheROCKET/flowblueprint/main/docs/media/<name>.gif)
  ```

  Use this full link rather than `docs/media/<name>.gif`: PyPI shows the
  README too, and only a full link works there. GitHub shows the GIF as
  soon as it is pushed; the PyPI page changes with the next release.

  For the website, copy the GIF into `site/` and add an `<img>` after the
  commands (the page is generated by the landing-page script).
